# Visual sources

`public/images/river-illustration.svg` is an original conceptual river illustration written as SVG for this guide. `public/images/social.png` is its reproducible PNG rendering. The inline SVG river lines and confluence mark are interface graphics. None represents a geographic map, an observed landscape or current visitor conditions.

The previous reference photographs and graphics had no verified per-file licence record and are no longer distributed. A historical Commons replacement was investigated, but its original file could not be obtained reliably; no copy of it is published here.
