# Visual sources

`public/images/river-illustration.svg` is an original conceptual river illustration written as SVG for this guide. `public/images/social.svg` is the dedicated 1200×630 sharing illustration. Its reviewed rendering is committed as `public/images/social.png`; normal builds verify and copy those exact PNG bytes instead of rasterizing system fonts. Explicit re-rendering after a source change requires visual review and updating the hash in `scripts/social.mjs`. The inline SVG river lines and confluence mark are interface graphics. None represents a geographic map, an observed landscape or current visitor conditions.

The previous reference photographs and graphics had no verified per-file licence record and are no longer distributed. A historical Commons replacement was investigated, but its original file could not be obtained reliably; no copy of it is published here.
